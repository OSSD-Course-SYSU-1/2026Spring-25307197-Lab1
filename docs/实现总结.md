## 🔧 技术实现

### 核心技术栈

- **手势识别**：PanGesture + 速度计算
- **设备发现**：distributedDeviceManager API
- **数据传输**：distributedDataObject API
- **UI组件**：ArkUI + CustomDialog

### 关键算法

#### 1. 甩动检测算法
```typescript
// 计算瞬时速度
velocity = (currentOffset - lastOffset) / deltaTime * 16.67

// 计算平均速度（滑动窗口）
avgVelocity = sum(velocityHistory) / historySize

// 判断是否触发甩出
isFling = avgVelocity >= minVelocity && totalOffset >= minDistance
```

#### 2. 设备过滤算法
```typescript
// 过滤本地设备
availableDevices = allDevices.filter(d => d.deviceId !== localDeviceId)

// 按设备类型排序
sortedDevices = devices.sort((a, b) => {
  return deviceTypePriority[a.type] - deviceTypePriority[b.type];
});
```

#### 3. 数据序列化
```typescript
// TodoItem → 可序列化数据
```
