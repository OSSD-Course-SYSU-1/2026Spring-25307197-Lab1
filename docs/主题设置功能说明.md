# 主题设置功能使用说明

## 功能概述

已成功为主题管理器添加了完整的 UI 界面，用户可以在设置页面中切换不同的主题颜色。

## 功能位置

**路径：** 我的 → 设置 → 主题颜色

## 使用步骤

1. **进入设置页面**
   - 点击底部导航栏的"我的"标签
   - 点击"设置"菜单项

2. **切换主题**
   - 在设置页面顶部可以看到"主题颜色"设置项
   - 点击任意主题选项即可切换
   - 当前选中的主题会显示 ✓ 标记

## 可用主题

提供 5 种主题颜色选择：

| 主题 | 颜色代码 | 说明 |
|------|---------|------|
| 绿色 | #4CAF50 | 默认主题 |
| 蓝色 | #2196F3 | 蓝色主题 |
| 橙色 | #FF9800 | 橙色主题 |
| 紫色 | #9C27B0 | 紫色主题 |
| 青色 | #00BCD4 | 青色主题 |

## 功能特性

### ✅ 已实现功能

1. **主题切换 UI**
   - 在设置页面中显示主题选择器
   - 每个主题显示对应颜色的圆点预览
   - 当前主题显示选中标记

2. **实时切换**
   - 点击主题选项立即切换
   - 无需重启应用

3. **持久化存储**
   - 主题选择自动保存到 Preferences
   - 应用重启后自动加载上次选择的主题
   - 首次使用默认加载绿色主题

4. **完整的颜色配置**
   - 每个主题包含完整的颜色方案
   - 主色、浅色、深色、强调色
   - 背景色、卡片背景色
   - 文本色、次要文本色、分割线颜色

```
commons/common_lib/src/main/ets/

```

### 核心组件

#### 1. ThemeSelector 组件
- 显示所有可用主题列表
- 每个主题项包含：颜色圆点、名称、选中标记
- 点击切换主题

#### 2. ThemeManager 工具类
- 管理主题状态
- 处理主题切换
- Preferences 持久化存储

## 使用示例

### 在其他页面中使用主题颜色

```typescript
import { ThemeManager, ThemeColors } from '@ohos_agcit/daily_schedule_common_lib';

@Component
struct MyPage {
  @State colors: ThemeColors = ThemeManager.instance.currentColors;

  build() {
    Column() {
      Text('示例文本')
        .fontColor(this.colors.text)
        .backgroundColor(this.colors.primary)
    }
    .backgroundColor(this.colors.background)
  }
}
```

### 监听主题变化

```typescript
import { ThemeManager, ThemeType } from '@ohos_agcit/daily_schedule_common_lib';

// 获取当前主题
const currentTheme = ThemeManager.instance.currentTheme;

// 判断是否为某个主题
if (currentTheme === ThemeType.BLUE) {
  console.log('当前是蓝色主题');
}
```

## 后续扩展建议

### 1. 主题变化通知
可以添加主题变化监听机制，让所有使用主题颜色的组件自动更新：

```typescript
// 在 ThemeManager 中添加
@Monitor('currentTheme')
onThemeChange() {
  // 通知所有订阅者主题已变化
}
```

### 2. 自定义主题
可以扩展支持用户自定义主题颜色：

```typescript
// 添加自定义主题
ThemeManager.instance.addCustomTheme({
  name: '自定义',
  colors: {
    primary: '#FF0000',
    // ... 其他颜色
  }
});
```

### 3. 主题预览
可以在主题选择器中添加更丰富的预览：

```typescript
// 显示主题预览卡片
@Builder
ThemePreview(theme: ThemeType) {
  Column() {
    // 使用该主题的预览内容
  }
  .backgroundColor(ThemeManager.instance.getThemeColors(theme).background)
}
```

## 注意事项

1. **初始化时机**：ThemeManager 已在应用启动时自动初始化
2. **默认主题**：首次使用默认加载绿色主题
3. **持久化**：主题选择会自动保存，无需手动操作
4. **性能**：主题切换是即时生效的，不会影响应用性能
