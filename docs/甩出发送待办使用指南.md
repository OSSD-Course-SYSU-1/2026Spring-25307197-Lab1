# 甩出发送待办功能使用指南

## 功能概述

本功能实现了通过甩动手势将待办事项发送到其他设备的能力。用户只需对待办卡片进行甩出操作，系统会自动打开设备选择列表，选择目标设备后即可完成发送。

## 核心组件

### 1. FlingTodoCard / FlingTodoListItem
可甩出的待办卡片组件，包装普通待办列表项，添加甩出发送功能。

### 2. DeviceSelectDialog
设备选择对话框，用于显示可用设备列表并处理设备选择。

### 3. FlingDetector
甩动检测器，检测用户的手势甩出动作。

### 4. TransferUtil
传输工具，负责跨设备数据传输。

### 5. DeviceManagerUtil
设备管理工具，负责设备发现和管理。

## 使用方法

### 方法一：使用 FlingTodoListItem 包装现有组件

```typescript
import { FlingTodoListItem, TodoItem } from '@ohos_agcit/daily_schedule_component_lib';

@ComponentV2
struct MyTodoList {
  @Local todoItems: TodoItem[] = [];
  
  build() {
    List({ space: 12 }) {
      ForEach(this.todoItems, (item: TodoItem) => {
        ListItem() {
          FlingTodoListItem({
            todoItem: item,
            onFlingSuccess: () => {
              console.info('发送成功');
            },
            content: () => {
              // 原有的待办卡片UI
              this.myTodoCard(item);
            }
          });
        }
      }, (item: TodoItem) => item.taskID)
    }
  }
  
  @Builder
  myTodoCard(item: TodoItem) {
    Row() {
      // 你的待办卡片UI实现
    }
  }
}
```

## 初始化配置

### 1. 在 EntryAbility 中初始化

```typescript
import { DeviceManagerUtil, TransferUtil } from '@ohos_agcit/daily_schedule_common_lib';
import { TodoItem } from '@ohos_agcit/daily_schedule_component_lib';

export default class EntryAbility extends UIAbility {
  async onCreate(want: Want, launchParam: AbilityConstant.LaunchParam) {
    // 初始化设备管理器
    const deviceManager = DeviceManagerUtil.getInstance();
    await deviceManager.init(this.context.applicationInfo.name);
    
    // 初始化传输工具
    const transferUtil = TransferUtil.getInstance();
    await transferUtil.init(this.context, this.context.applicationInfo.name);
    
    // 注册接收回调
    transferUtil.registerReceiveCallback({
      onTodoReceived: (todo: TodoItem, fromDeviceId: string) => {
        console.info(`收到待办: ${todo.title} 来自设备: ${fromDeviceId}`);
        // 处理接收到的待办事项
        // 例如：添加到本地待办列表
      },
      onBatchReceived: (todos: TodoItem[], fromDeviceId: string) => {
        console.info(`收到${todos.length}个待办 来自设备: ${fromDeviceId}`);
        // 批量处理
      }
    });
  }
  
  onDestroy() {
    // 释放资源
    TransferUtil.getInstance().release();
    DeviceManagerUtil.getInstance().release();
  }
}
```

### 2. 配置权限

在 `module.json5` 中添加必要的权限：

```json
{
  "module": {
    "requestPermissions": [

      },
      {
        "name": "ohos.permission.GET_NETWORK_INFO",
        "reason": "用于获取网络信息"
      }
    ]
  }
}
```

## 功能特性

### 1. 甩动手势识别
- 支持四个方向的甩出（上、下、左、右）
- 可配置最小速度阈值（默认18像素/帧）
- 可配置最小距离阈值（默认100像素）
- 智能速度计算，避免误触发

### 2. 设备发现与选择
- 自动发现同一账号下的可用设备
- 过滤本地设备，避免发送给自己
- 显示设备类型图标（手机、平板、电视、手表等）
- 支持设备在线状态显示

### 3. 数据传输
- 基于HarmonyOS分布式数据对象
- 支持单个待办发送
- 支持批量待办发送
- 自动处理传输状态和错误

### 4. 视觉反馈
- 拖拽时卡片放大和阴影效果
- 甩出动画流畅自然
- 回弹动画（未触发甩出时）
- 加载状态提示

## 注意事项

1. **设备要求**：所有设备需要登录同一华为账号
2. **网络要求**：设备需要在同一局域网或通过分布式软总线连接
3. **权限配置**：确保已配置分布式数据同步权限
4. **初始化顺序**：先初始化DeviceManagerUtil，再初始化TransferUtil
5. **资源释放**：在Ability销毁时释放相关资源

## 故障排查

### 1. 无法发现设备
- 检查设备是否登录同一账号
- 检查网络连接状态
- 检查是否配置了必要权限

### 2. 发送失败
- 检查目标设备是否在线
- 检查数据格式是否正确
- 查看日志输出定位具体错误

### 3. 甩出不触发
- 调整速度和距离阈值
- 检查手势是否被其他组件拦截
- 确保组件层级正确

## 技术架构

```
用户甩出手势
    ↓
FlingDetector 检测甩出
    ↓
FlingTodoCard/FlingTodoListItem 处理甩出事件
    ↓
DeviceSelectDialog 显示设备列表
    ↓
用户选择目标设备
    ↓
TransferUtil 发送待办数据
    ↓
目标设备接收数据（通过分布式数据对象）
    ↓
目标设备处理接收到的待办
```
