# 甩出发送动画效果增强说明

## 概述

为甩出发送功能添加了丰富的动画效果，显著提升用户体验。新增的动画效果包括：

1. **拖拽阶段动画**
2. **甩出阶段动画**
3. **发送状态动画**
4. **成功反馈动画**

## 新增文件

### 1. FlingAnimationEffects.ets
路径：`commons/component_lib/src/main/ets/components/FlingAnimationEffects.ets`

提供多种动画效果组件：

#### FlingAnimationEffects
主动画效果组件，支持4种动画类型：
- **particle**: 粒子扩散效果（20个粒子向外扩散）
- **glow**: 光晕效果（多层光晕扩散）
- **progress**: 进度环动画（显示发送进度）
- **success**: 成功动画（✓图标 + 涟漪扩散）

#### DragDirectionIndicator
拖拽方向指示器组件：
- 显示拖拽方向箭头
- 根据速度强度显示不同颜色：
  - 灰色：速度 < 10（不够甩出）
  - 橙色：速度 10-18（接近甩出）
  - 绿色：速度 >= 18（可以甩出）

#### SendStatusAnimation
发送状态动画组件：
- **preparing**: 准备发送状态
- **sending**: 发送中状态（双环旋转动画）
- **success**: 发送成功状态
- **failed**: 发送失败状态

## 更新文件

### 1. FlingTodoCard.ets
路径：`commons/component_lib/src/main/ets/components/FlingTodoCard.ets`

增强了 `FlingTodoListItem` 组件，集成所有动画效果：

#### 拖拽阶段
- 卡片轻微放大（1.02倍）
- 绿色光晕阴影，强度随速度动态变化
- 方向指示器实时显示甩出方向
- 速度可视化反馈

#### 甩出阶段
- 粒子扩散效果（20个粒子）
- 卡片沿甩出方向飞出屏幕
- 透明度渐变消失
- 缩放动画

#### 发送阶段
- 显示设备选择对话框
- 发送状态提示

#### 成功阶段
- 成功图标动画（✓）
- 涟漪扩散效果
- 震动反馈（如果设备支持）

## 使用方法

### 基础用法

```typescript
import { FlingTodoListItem } from '@ohos_agcit/daily_schedule_component_lib';

FlingTodoListItem({
  todoItem: item,
  onFlingSuccess: () => {
    console.info('发送成功');
  },
  content: () => {
    // 原始卡片内容
    this.TodoCardBuilder(item);
  }
})
```

### 自定义动画

```typescript
import { FlingAnimationEffects } from '@ohos_agcit/daily_schedule_component_lib';

// 粒子效果
FlingAnimationEffects({
  isVisible: true,
  centerX: 200,
  centerY: 300,
  animationType: 'particle',
  particleColor: '#4CAF50'
})

// 成功动画
FlingAnimationEffects({
  isVisible: true,
  centerX: 200,
  centerY: 300,
  animationType: 'success',
  particleColor: '#4CAF50'
})
```

## 动画效果详解

### 1. 粒子扩散效果
- 20个粒子均匀分布
- 从中心向外扩散
- 透明度渐变消失
- 尺寸逐渐缩小
- 持续时间：40帧（约640ms）

### 2. 光晕效果
- 三层光晕（外层、内层、核心）
- 半径逐渐扩大
- 透明度正弦变化
- 持续时间：30帧（约480ms）

### 3. 进度环动画
- 背景环 + 进度环
- 中心显示百分比
- 旋转装饰效果

### 4. 成功动画
- 成功图标（✓）缩放出现
- 涟漪向外扩散
- 透明度渐变
- 持续时间：25帧（约400ms）

## 性能优化

1. **硬件加速**
   - 使用 `animateTo` 实现硬件加速动画
   - 采用 `curves.springMotion` 提供自然动画曲线

2. **资源管理**
   - 及时清理动画定时器
   - 组件销毁时停止所有动画
   - 避免内存泄漏

3. **渲染优化**
   - 使用 `@Local` 状态管理动画属性
   - 最小化重绘范围
   - 优化粒子数量（20个）

## 注意事项

1. **性能考虑**
   - 避免同时触发多个粒子效果
   - 在低端设备上可能需要降低粒子数量
   - 建议在 `aboutToDisappear` 中清理资源

2. **可访问性**
   - 提供了文字状态说明
   - 颜色不是唯一的信息传达方式
   - 考虑动画敏感用户

3. **兼容性**
   - 震动反馈需要设备支持
   - 部分动画效果需要硬件加速支持
   - 建议在不同设备上测试
