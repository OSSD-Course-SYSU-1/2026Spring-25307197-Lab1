# 甩出发送功能操作指南

## 📱 功能概述

甩出发送是一种通过手势快速将待办事项发送到其他设备的交互方式。用户只需拖拽待办卡片并快速甩出，即可触发发送流程。

---

## 🎯 操作步骤详解

### 步骤 1：进入待办列表页面

1. 打开应用
2. 进入待办事项列表页面
3. 找到需要发送的待办事项

### 步骤 2：开始拖拽

**操作方法：**
- 手指按住待办卡片不放
- 等待约 0.2 秒（卡片会轻微放大）

**视觉反馈：**
- ✅ 卡片轻微放大（1.02倍）
- ✅ 出现绿色光晕阴影
- ✅ 卡片浮起效果

**提示：**
- 不要立即移动，先等待卡片响应
- 确保手指按在卡片有效区域内

### 步骤 3：拖拽移动

**操作方法：**
- 保持按住状态
- 向任意方向移动手指
- 移动距离建议超过 80 像素

**视觉反馈：**
- ➡️ 出现方向指示器（箭头）
- 🎨 方向指示器颜色变化：
  - **灰色**：速度 < 10（甩出力度不够）
  - **橙色**：速度 10-18（接近甩出阈值）
  - **绿色**：速度 ≥ 18（可以甩出）
- 💫 光晕强度随速度增强

**技巧：**
- 缓慢移动：只会看到拖拽效果，不会触发甩出
- 快速移动：更容易触发甩出

### 步骤 4：快速甩出

**操作方法：**
- 快速向一个方向滑动（推荐向上或向右）
- 松开手指
- 滑动速度要快（类似快速划走卡片）

**判定条件：**
- ✅ 速度 ≥ 18 像素/帧
- ✅ 移动距离 ≥ 80 像素
- 两个条件同时满足才会触发甩出

**视觉反馈：**
- ✨ 粒子扩散效果（20个绿色粒子向外扩散）
- 🚀 卡片沿甩出方向飞出屏幕
- 🌟 卡片透明度渐变消失
- 📐 卡片缩放动画

**推荐甩出方向：**
- ⬆️ 向上甩出：归档/完成操作
- ➡️ 向右甩出：确认/发送操作
- ⬇️ 向下甩出：删除操作
- ⬅️ 向左甩出：取消/拒绝操作

### 步骤 5：选择目标设备

**操作方法：**
1. 甩出成功后，自动弹出设备选择对话框
2. 等待设备列表加载（显示"正在搜索设备..."）
3. 从列表中选择目标设备
4. 点击"发送"按钮

**对话框内容：**
- 📱 设备图标（手机/平板/电视/手表）
- 📝 设备名称
- 🏷️ 设备类型
- ✓ 选中状态标记

**注意事项：**
- 如果没有发现设备，会提示"暂无设备"
- 确保目标设备已开启并登录同一华为账号
- 确保两台设备在同一网络下

### 步骤 6：发送完成

**操作方法：**
- 点击发送按钮后，等待发送完成

**视觉反馈：**
- 🔄 发送中：双环旋转动画
- ✅ 发送成功：
  - 成功图标动画（✓）
  - 涟漪扩散效果
  - Toast 提示"发送成功"
  - 可选：震动反馈
- ❌ 发送失败：
  - 失败图标（✗）
  - Toast 提示错误信息

      if (this.showMockDevices) {

      }
    }
  }
  
  @Builder
  MockDeviceDialog() {
    Column() {
      Text('模拟设备列表')
        .fontSize(20)
        .fontWeight(FontWeight.Bold)
      
      // 模拟设备

  @Builder

      Text(item.title)
        .fontSize(16)
    }
    .width('100%')
    .height(80)
    .padding(16)
    .backgroundColor('#FFFFFF')
    .borderRadius(12)
  }
}

## 📲 真实设备使用方法

### 前置条件

1. **设备要求**
   - 两台或多台 HarmonyOS 设备
   - 设备系统版本 ≥ API 9
   - 设备支持分布式能力

2. **账号要求**
   - 所有设备登录同一华为账号
   - 账号已实名认证

3. **网络要求**
   - 所有设备连接同一 WiFi 网络
   - 或开启蓝牙近距离发现

4. **权限要求**
   - 应用已获取分布式权限
   - 应用已获取设备信息权限

### 使用步骤

1. **准备工作**
   - 在设备 A 上打开应用
   - 在设备 B 上打开应用
   - 等待设备互相发现（约 5-10 秒）

2. **执行甩出发送**
   - 在设备 A 上，按住待办卡片
   - 快速向上或向右甩出
   - 在弹出的设备列表中选择设备 B
   - 点击发送按钮

3. **确认接收**
   - 设备 B 会自动接收待办
   - 设备 B 上会显示新待办通知
   - 待办自动添加到设备 B 的列表中

### 常见问题

#### Q1: 找不到其他设备？

**解决方案：**
1. 确认两台设备登录同一华为账号
2. 确认两台设备在同一 WiFi 网络
3. 尝试重启应用
4. 检查分布式权限是否开启
5. 查看系统设置中的"超级终端"功能

#### Q2: 发送失败？

**解决方案：**
1. 检查网络连接状态
2. 确认目标设备应用在前台运行
3. 查看日志错误信息
4. 尝试重新发送

#### Q3: 甩出没有反应？

**解决方案：**
1. 确认甩出速度足够快
2. 确认移动距离超过 80 像素
3. 尝试不同方向甩出
4. 检查是否正确触发手势

## 💡 使用技巧

### 1. 手势技巧

- **快速甩出**：像划走卡片一样快速滑动
- **方向选择**：向上或向右甩出最自然
- **力度控制**：速度越快，动画越明显

### 2. 视觉提示

- **颜色含义**：
  - 灰色 = 再快一点
  - 橙色 = 快了
  - 绿色 = 可以甩出
- **方向箭头**：指示甩出方向

### 3. 最佳实践

- 在列表项较少时使用，避免误触
- 在网络良好时使用，提升发送成功率
- 发送前确认目标设备在线

## 📊 性能数据

### 手势识别

- 最小速度阈值：18 像素/帧
- 最小距离阈值：80 像素
- 速度采样窗口：5 帧
- 响应延迟：< 50ms

### 动画性能

- 粒子数量：20 个
- 粒子动画帧率：60 FPS
- 粒子生命周期：640ms
- 内存占用：< 1MB

### 发送性能

- 设备发现时间：5-10 秒
- 数据传输时间：100-500ms
- 总耗时：1-2 秒
