# 快速开始：甩出发送待办功能

## 一分钟快速集成

### 步骤1：导入组件（10秒）

在你的待办列表组件中添加导入：

```typescript
import { FlingTodoListItem } from '@ohos_agcit/daily_schedule_component_lib';
```

### 步骤2：包装待办卡片（30秒）

用 `FlingTodoListItem` 包装你现有的待办卡片：

```typescript
// 修改前
ListItem() {
  Row() {
    // 你的待办卡片UI
  }
}

// 修改后
ListItem() {
  FlingTodoListItem({
    todoItem: item,  // 待办数据
    onFlingSuccess: () => {
      console.info('发送成功！');
    },
    content: () => {
      // 你的待办卡片UI（保持不变）
      Row() {
        // ...
      }
    }
  });
}
```

### 步骤3：初始化（20秒）

在 `EntryAbility.onCreate` 中添加初始化代码：

```typescript
import { DeviceManagerUtil, TransferUtil } from '@ohos_agcit/daily_schedule_common_lib';

export default class EntryAbility extends UIAbility {
  async onCreate(want: Want, launchParam: AbilityConstant.LaunchParam) {
    // 初始化
    const deviceManager = DeviceManagerUtil.getInstance();
    await deviceManager.init(this.context.applicationInfo.name);
    
    const transferUtil = TransferUtil.getInstance();
    await transferUtil.init(this.context, this.context.applicationInfo.name);
    
    // 接收数据
    transferUtil.registerReceiveCallback({
      onTodoReceived: (todo, fromDevice) => {
        console.info(`收到: ${todo.title}`);
      }
    });
  }
}
```

## 完成！🎉

现在你可以：
1. **长按**待办卡片
2. **快速甩出**（任意方向）
3. **选择设备**
4. **自动发送**

## 常见问题

<details>
<summary>Q: 找不到设备？</summary>

**A:** 确保：
- 所有设备登录同一华为账号
- 设备在同一局域网
- 已配置分布式权限
</details>

<details>
<summary>Q: 甩出不触发？</summary>

**A:** 尝试：
- 更快的甩动速度
- 更长的甩动距离
- 检查是否初始化成功
</details>

<details>
<summary>Q: 发送失败？</summary>

**A:** 检查：
- 目标设备是否在线
- 查看日志错误信息
- 确认权限配置正确
</details>
