# 主题切换调试说明

## 问题诊断

已添加详细的日志输出，帮助诊断主题切换问题。

## 如何查看日志

### 方法1：使用 DevEco Studio 的 HiLog 工具

1. 在 DevEco Studio 底部工具栏点击 **HiLog** 标签
2. 在过滤器中输入以下关键词：
   - `ThemeManager` - 查看主题管理器日志
   - `ThemeSelector` - 查看主题选择器日志
3. 点击主题选项，观察日志输出

### 方法2：使用 hdc 命令行工具

```bash
# 查看所有主题相关日志
hdc shell hilog | grep -E "ThemeManager|ThemeSelector"

# 或者只查看 ThemeManager 日志
hdc shell hilog | grep ThemeManager
```

## 预期的日志输出

### 正常情况下的日志流程：

```
// 应用启动时
ThemeManager: init success, current theme: green

// 进入设置页面时
ThemeSelector: init, current theme: green

// 点击"蓝色"主题时
ThemeSelector: onThemeChange: blue, current: green
ThemeManager: switching from green to blue
ThemeManager: themeState.currentTheme updated to blue
ThemeManager: saved theme to preferences: blue
ThemeManager: switched to theme blue
ThemeSelector: after switch, current theme: blue
```

### 如果出现问题的日志：

```
// 如果 themeState 是 null
ThemeManager: themeState is null

// 如果主题已经是当前主题
ThemeSelector: theme is already active, return
ThemeManager: theme blue is already active
```

## 关键检查点

### 1. ThemeManager 初始化

✅ **正确：** 在应用启动时看到 `ThemeManager: init success`
❌ **错误：** 没有看到初始化日志

**解决方案：** 检查 EntryAbility.ets 中是否调用了 `ThemeManager.instance.init(this.context)`

### 2. ThemeState 实例一致性

✅ **正确：** ThemeSelector 和 ThemeManager 使用同一个 ThemeState 实例
❌ **错误：** 它们使用不同的实例

**检查方法：** 在日志中查看 ThemeState 的内存地址是否一致

### 3. 主题切换执行

✅ **正确：** 看到 `switching from X to Y` 和 `switched to theme Y`
❌ **错误：** 只看到 `onThemeChange` 但没有后续日志

**可能原因：**
- ThemeManager.themeState 为 null
- 主题已经是当前主题

## 已修复的问题

### 问题1：ThemeState 实例不一致

**原因：** ThemeSelector 和 ThemeManager 各自创建 ThemeState 实例
**修复：** ThemeSelector 现在通过 `ThemeManager.instance.getThemeState()` 获取实例

### 问题2：AppStorageV2 连接问题

**原因：** AppStorageV2.connect 可能在不同时机创建不同实例
**修复：** 确保 ThemeManager 在应用启动时就初始化并创建实例

## 测试步骤

1. **清理应用数据**
   ```bash
   hdc shell rm -rf /data/local/tmp/*.json
   ```

2. **重新安装应用**
   - 在 DevEco Studio 中点击 Run

3. **打开 HiLog 工具**
   - 过滤关键词：`ThemeManager|ThemeSelector`

4. **测试主题切换**
   - 进入"我的" → "设置"
   - 点击不同的主题选项
   - 观察日志输出和 UI 变化

5. **验证持久化**
   - 切换主题后退出应用
   - 重新打开应用
   - 检查主题是否保持

### 添加更多日志

如果需要更详细的调试信息，可以在 ThemeManager.ets 中添加：

```typescript
public switchTheme(theme: ThemeType): void {
  Logger.info(`ThemeManager: switchTheme called`);
  Logger.info(`ThemeManager: themeState exists: ${this.themeState !== null}`);
  Logger.info(`ThemeManager: current theme: ${this.themeState?.currentTheme}`);
  Logger.info(`ThemeManager: target theme: ${theme}`);
  Logger.info(`ThemeManager: themes are equal: ${this.themeState?.currentTheme === theme}`);
  
  // ... 原有代码
}
```

### 检查 AppStorageV2 状态

在 ThemeSelector 中添加：

```typescript
aboutToAppear(): void {
  hilog.info(DOMAIN, 'ThemeSelector', `themeState: ${JSON.stringify(this.themeState)}`);
  hilog.info(DOMAIN, 'ThemeSelector', `currentTheme: ${this.themeState.currentTheme}`);
  hilog.info(DOMAIN, 'ThemeSelector', `Manager theme: ${ThemeManager.instance.currentTheme}`);
}
```

## 下一步

如果日志显示一切正常但 UI 仍然没有更新，可能是：

1. **UI 绑定问题** - @Local 装饰器没有正确触发更新
2. **组件生命周期问题** - 组件没有重新渲染
3. **AppStorageV2 问题** - 状态同步机制有问题

请查看日志并反馈结果，我们将根据具体情况进一步调整。
