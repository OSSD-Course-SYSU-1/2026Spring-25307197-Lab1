# 拖拽组件使用说明

## 功能特性

已实现以下功能：

### 1. 长按触发拖动
- 长按列表项 400-500ms 后进入拖动模式
- 拖动模式下列表项变为半透明占位

### 2. 悬浮预览效果
- 拖动时显示放大的预览（默认 1.05-1.1 倍缩放）
- 添加阴影效果，营造悬浮感
- 预览项跟随手指移动

### 3. 物理甩动效果
- 根据拖动速度计算惯性
- 摩擦系数 0.82，模拟自然减速
- 边界弹性系数 0.35，到达边界时反弹
- 甩动结束后自动吸附到目标位置

### 4. 列表项动画
- 其他列表项平滑移动为新位置腾出空间
- 使用 springMotion 曲线，动画流畅自然

## 组件说明

### DraggableList（通用拖拽列表）

适用于任意数据类型的可拖拽列表。

```typescript
import { DraggableList, DraggableItem } from '@ohos_agcit/daily_schedule_component_lib';

// 定义数据
@Local items: DraggableItem[] = [
  { id: '1', content: '项目一', color: '#FF6B6B' },
  { id: '2', content: '项目二', color: '#4ECDC4' },
  // ...
];

// 使用组件
DraggableList({
  items: this.items,
  itemHeight: 80,              // 列表项高度
  itemSpacing: 12,             // 列表项间距
  longPressDuration: 400,      // 长按触发时间（毫秒）
  previewScale: 1.08,          // 悬浮预览缩放比例
  previewShadowRadius: 35,     // 悬浮预览阴影半径
  friction: 0.82,              // 物理甩动摩擦系数
  elasticity: 0.35,            // 边界弹性系数
  itemBuilder: (item: DraggableItem, index: number, isDragging: boolean) => {
    // 自定义列表项外观
    this.myItemBuilder(item, index, isDragging);
  },
  onDragEnd: (newItems: DraggableItem[]) => {
    // 拖拽结束回调，更新数据
    this.items = newItems;
  }
})
```

### DraggableTodoList（待办事项拖拽列表）

专为待办事项设计的拖拽列表，内置默认样式。

```typescript
import { DraggableTodoList } from '@ohos_agcit/daily_schedule_component_lib';
import { TodoItem } from '@ohos_agcit/daily_schedule_component_lib';

// 使用组件
DraggableTodoList({
  todoItems: this.todoItems,       // TodoItem 数组
  itemHeight: 76,                  // 列表项高度
  itemSpacing: 12,                 // 列表项间距
  longPressDuration: 500,          // 长按触发时间
  maxTitleLen: 16,                 // 最大标题长度
  onDelete: (taskID: string) => {  // 删除回调
    // 处理删除
  },
  onModify: (taskID: string) => {  // 修改回调
    // 处理修改
  },
  onFinishChange: (taskID: string, isFinished: boolean) => {  // 完成状态改变
    // 更新完成状态
  },
  onDragEnd: (fromIndex: number, toIndex: number) => {  // 拖拽结束
    // 交换数据位置
    let tmp = this.todoItems.splice(fromIndex, 1);
    this.todoItems.splice(toIndex, 0, tmp[0]);
  }
})
```

## 参数说明

### DraggableList 参数

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| items | DraggableItem[] | [] | 数据源 |
| itemHeight | number | 80 | 列表项高度（vp） |
| itemSpacing | number | 12 | 列表项间距（vp） |
| longPressDuration | number | 400 | 长按触发时间（毫秒） |
| previewScale | number | 1.05 | 悬浮预览缩放比例 |
| previewShadowRadius | number | 30 | 悬浮预览阴影半径 |
| friction | number | 0.85 | 物理甩动摩擦系数（0-1） |
| elasticity | number | 0.4 | 边界弹性系数（0-1） |
| itemBuilder | Builder | - | 列表项构建器 |
| onDragEnd | Function | - | 拖拽结束回调 |

### DraggableItem 数据结构

```typescript
interface DraggableItem {
  id: string;           // 唯一标识
  content: string;      // 内容
  color: ResourceColor; // 颜色
}
```

## 物理效果原理

### 速度计算
- 记录最近 5 次移动的速度
- 计算平均速度，减少抖动
- 释放时的速度 = 平均速度 × 2（放大系数）

### 摩擦减速
- 每帧速度 = 当前速度 × 摩擦系数
- 摩擦系数 0.82 模拟空气阻力
- 速度小于阈值时停止

### 边界弹性
- 超出边界时反弹
- 反弹速度 = 超出速度 × 弹性系数
- 弹性系数 0.35 模拟能量损失

### 目标吸附
- 计算当前位置对应的目标索引
- 甩动结束后平滑移动到目标位置
- 使用 springMotion 曲线实现弹性动画

## 最佳实践

### 1. 性能优化
- 限制列表项数量（建议不超过 50 项）
- 使用简单的列表项布局
- 避免在 itemBuilder 中执行耗时操作

### 2. 用户体验
- 长按时间建议 400-500ms
- 缩放比例建议 1.05-1.1
- 摩擦系数建议 0.8-0.85
- 弹性系数建议 0.3-0.4

### 3. 数据更新
- 拖拽结束后立即更新数据
- 使用展开运算符创建新数组
- 触发 UI 刷新

### 4. 自定义样式
- 使用 itemBuilder 完全自定义外观
- isDragging 参数可改变拖拽时的样式
- 添加拖拽图标提示用户可拖拽

## 注意事项

1. **数据唯一性**：每个列表项必须有唯一的 id
2. **高度固定**：所有列表项高度必须相同
3. **状态管理**：使用 @Local 管理拖拽状态
4. **手势冲突**：避免与其他手势同时使用
5. **性能考虑**：大量数据时考虑虚拟滚动
